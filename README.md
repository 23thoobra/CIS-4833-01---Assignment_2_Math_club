# CIS-4833-01---Assignment_2_Math_club
Two-page HTML5 club website (Maverick Math Club) for CIS 483/583 Homework 2. It uses semantic layout, relative navigation, accessible images, lists, an events table with caption and scope, and a validated registration form with labels, required fields, and ARIA. Pure HTML, no CSS or JS, and it passes the W3C validator. Styled later in HW3.
